# JADE - User Guide

## 🎯 Getting Started with JADE

Welcome to JADE, your creative companion platform! This guide will walk you through all features.

---

## 📚 Section 1: Inspiration Library

### What is the Inspiration Library?

A personal space to collect and organize creative inspiration from anywhere on the internet.

### How to Use

1. **Add Inspiration**
   - Click "+ New Inspiration" button
   - Fill in details:
     - **Title**: Give it a catchy name
     - **Content**: Write a description or quote
     - **Category**: Choose (book, website, design, copywriting, visual, other)
     - **Tags**: Add searchable tags (e.g., #sunset, #design, #quotes)
     - **Source**: Link to original source (optional)
     - **Image**: Upload a photo (optional)
   - Click "Save"

2. **Browse Inspiration**
   - Scroll through your inspiration cards
   - Use search bar to find specific items
   - Filter by category
   - Click "Like" to favorite an item

3. **Organize**
   - Use tags to group related inspirations
   - Create collections (coming soon)
   - Export as PDF (coming soon)

### Tips

- 💡 Add inspiration regularly (daily if possible)
- 🏷️ Use consistent tags for better organization
- 📸 Include images for visual reference
- 🔗 Save sources for attribution

## 💡 Section 2: AI Creative Workshop

### What is the Workshop?

A private space where you can brainstorm with 4 different AI models simultaneously.

### How to Use

1. **Start a Session**
   - Click "Workshop" in navigation
   - Give your session a title
   - Click "New Workshop"

2. **Chat with AI**
   - Type your prompt/question in the input box
   - Press "Send" or hit Enter
   - Watch all 4 AI models respond simultaneously:
     - 🤖 **OpenAI (GPT-4)** - Advanced reasoning, creative writing
     - 🧠 **Claude** - Thoughtful, nuanced responses
     - ✨ **Gemini** - Fast, helpful responses
     - 🚀 **DeepSeek** - Detailed technical responses

3. **Use Inspiration**
   - Link inspiration items to your workshop
   - AI will reference them in responses
   - Create variations with different prompts

4. **Save Ideas**
   - Each conversation is auto-saved
   - Export as Markdown (coming soon)
   - Convert to portfolio item (coming soon)

### Example Prompts

**For Copywriting:**
```
Help me write a compelling social media caption for a sunset photo.
Include emojis and a call-to-action.
```

**For Photography:**
```
What are some creative composition ideas for a portrait photoshoot?
Consider lighting, angles, and background.
```

**For Music:**
```
I want to create a song about personal growth.
Suggest lyrics, melody ideas, and instruments.
```

**For Handicraft:**
```
Design ideas for a handmade jewelry business.
Consider materials, styles, and target audience.
```

### Tips

- 🎯 Be specific in your prompts
- 🔄 Try variations of the same prompt
- 💾 Save good responses
- 🤝 Compare AI responses to choose the best one
- 📝 Use the workshop to outline your work

## 🌟 Section 3: Portfolio Showcase

### What is Portfolio?

Your public space to display finished creative works.

### How to Use

1. **Create Portfolio Item**
   - Click "Portfolio" → "+ New Work"
   - Fill in details:
     - **Title**: Name of your work
     - **Description**: What's the story?
     - **Type**: Choose category
       - 📸 Photography
       - ✍️ Copywriting
       - 🎵 Music
       - 🧶 Handicraft
     - **Image**: Upload your work (required)
     - **Content URL**: Link to your work (optional)
     - **Related Inspiration**: Link inspiration that inspired this
   - Choose visibility: Private or Published
   - Click "Publish"

2. **Browse Others' Work**
   - Visit `/portfolio` to see all public works
   - Filter by type
   - Like and comment on work you enjoy

3. **Manage Your Portfolio**
   - Edit unpublished works
   - Delete items (coming soon)
   - Reorder works (coming soon)
   - View statistics (coming soon)

### Commenting

- Visitors can leave anonymous comments
- Comments are moderated before appearing
- You'll be notified of new comments
- Reply to comments (coming soon)

### Tips

- 🎨 Curate your best works
- 📷 Use high-quality images
- 📝 Write compelling descriptions
- 🔗 Link inspiration sources
- 📊 Analyze what gets the most engagement

## 👤 Section 4: Your Profile

### Profile Setup

1. **Go to Settings**
   - Click your avatar → "Settings"
   - Update profile information:
     - **Profile Picture**: Upload a photo
     - **Bio**: Write about yourself
     - **Website**: Link to your portfolio site
     - **Social Links**: Instagram, Twitter, etc.

2. **Visibility**
   - Public profile: Others can see your work
   - Private profile: Work invitation-only
   - Anonymous mode: Hide your identity

3. **Privacy Settings**
   - Control who can comment on your work
   - Set moderation preferences
   - Manage followers (coming soon)

## 🔒 Section 5: Security & Privacy

### Account Security

- ✅ Use strong passwords (12+ characters)
- ✅ Never share your password
- ✅ Enable two-factor authentication (coming soon)
- ✅ Log out after using shared computers

### Data Privacy

- Your inspiration library is **private** (only you see it)
- Your workshops are **private** (only you see conversations)
- Your portfolio is **public by default** (you can make it private)
- Comments can be anonymous
- We never sell your data

### Copyright

- You own all content you create
- Respect others' copyright when sharing
- Give credit to inspiration sources
- Report stolen work to support@jade.com

## 🆘 Troubleshooting

### Can't log in?

1. Check email/password spelling
2. Reset password (coming soon)
3. Check if account is verified
4. Contact support@jade.com

### Can't upload images?

1. Check file size (max 5MB)
2. Check file format (JPG, PNG, WebP)
3. Check internet connection
4. Try a different browser

### AI not responding?

1. Check internet connection
2. Refresh the page
3. Check if API quota is exceeded
4. Try a different AI model

### Lost work?

1. All work is auto-saved
2. Check browser cache
3. Check browser history
4. Contact support (we keep backups)
